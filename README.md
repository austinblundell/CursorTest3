# Crystalfall Chronicles

A self-contained fantasy RPG built for the browser and GitHub Pages.

Play location once published:

https://austinblundell.github.io/CursorTest3/

## Features

- Pixel-art overworld rendered on an HTML canvas
- Keyboard, arrow-key, and mobile movement controls
- Turn-based party combat with attacks, spells, guarding, potions, and ethers
- Town rest/shop actions
- Three crystal guardian bosses and a final Shadow Spire boss
- Browser local-save support

No build step is required. GitHub Pages can serve `index.html`, `styles.css`,
and `game.js` directly from the repository root.
